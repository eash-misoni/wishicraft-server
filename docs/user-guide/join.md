## 参加に必要なもの

1. **Minecraft Java Edition {{version}}** の標準clientを用意します。A・Bとも同じ版のVanillaです。
2. 管理者に参加を相談し、Minecraftのwhitelist登録とDiscordのPlayer / Admin roleを確認します。Webを閲覧できることと、ゲームへの参加・コマンドの権限は別です。
3. 接続先とDiscordへの招待は管理者から個別に受け取ってください。このサイトには掲載しません。

追加のMODパック指定はありません。Bedrock Edition（統合版）接続やMOD入りclientの互換性は確認していません。同じ版の標準Java clientを使ってください。

## Gameを選んで参加する

[Game一覧](games.md)でA・Bの違いを確認します。同時に遊べるGameは一つです。
指定の操作チャンネルで [status](commands/status.md) を使い、停止中なら [start](commands/start.md) でGameを選んで起動します。
起動受付だけでは参加準備の完了ではありません。完了通知と状態を確認してから、Minecraftの「マルチプレイ」で案内された接続先へ参加します。

別Gameが稼働している場合、STARTでそのGameを止めることはできません。[switch](commands/switch.md) の条件を確認し、管理者へ相談してください。

## 参加できない場合

版、whitelist登録、案内された接続先を確認してください。接続先を自分で推測したり、コマンドを連打したりせず、[困ったとき](help.md)の手順で管理者に状況を伝えます。
