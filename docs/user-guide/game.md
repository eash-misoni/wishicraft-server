## 参加手順

1. 上記のedition・版・loader/MODパックを確認し、案内に従ってclientを準備します。未確認の項目があれば、接続する前に管理者へ確認してください。
2. {{access}}
3. 指定のDiscord操作チャンネルで [status](../commands/status.md) を使い、**参加したい {{game-name}}（`{{game-id}}`）が稼働していること**を確認します。共通接続先のため、何かのGameがREADYでも対象が違えば参加を進めません。
4. 停止中なら下のSTART例で対象Gameを指定します。別のGameが稼働中なら管理者へSWITCHを相談します。SWITCHはAdmin・観測0人・明示確認が必要で、直前接続raceも残ります。

{{game-examples}}

5. 完了通知を待ち、再度statusで選択Gameと観測Gameが **{{game-name}}（`{{game-id}}`）** であること、参加できる状態であることを確認します。受付や処理への到達だけで接続しません。
6. {{connection}} clientの接続画面で、個別に案内された接続先へ接続します。
