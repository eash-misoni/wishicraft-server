## 実行中と完了後

必要に応じてEC2を起動し、Minecraftの準備と対象Game、接続先の整合を確認します。受付応答やEC2起動だけで参加可能とは判断しません。
完了通知を待ち、[status](status.md)で対象と状態を確認してから参加してください。所要時間は固定保証しません。

同じGameがすでに準備完了なら、通常の観測・対象照合のもとで起動済み状態へ収束します。worldを作り直したり、強制的に再起動したりするcommandではありません。
別Gameが稼働している場合はSTARTで保存・停止しません。管理者の [switch](switch.md) の条件を確認してください。

## 拒否・失敗・結果不明

他の操作が進行中、観測不能、対象不一致などでは拒否や失敗になる場合があります。連打せずSTATUSを確認します。
応答不明や未解決の起動がある場合は、新しい要求を送る前に管理者へ相談してください。[困ったとき](../help.md)に確認手順があります。
