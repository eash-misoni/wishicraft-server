すべて指定のDiscord操作チャンネルで実行します。管理者も同じ操作チャンネルを使います。
STATUS以外は他の操作が進行している場合などに受け付けられないことがあります。人数不明は0人とは扱いません。

STARTとSWITCHは別操作です。STOPやRESETを実行しても、毎回の外部BACKUPが更新されるわけではありません。
結果不明のときは新しい要求で埋め合わせず、[困ったとき](help.md)を確認してください。
