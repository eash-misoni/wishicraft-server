同時に遊べるGameは一つです。必要なclient条件はGameごとに確認してください。
共通接続先へ入る前に、参加したいGameが稼働していることを [status](commands/status.md) で確認します。
申請や権限の補足は [共通の準備](join.md) を参照してください。

正式登録されたACTIVEなGameを、ページを開くたびに表示します。
作成後に一覧の配布・Discord command再登録は不要です。
NeoForgeなどのMOD構成は管理Webのclient要件を確認してください。

[従来のVanilla Main参加手順](games/a.md)・[Vanilla Secondary参加手順](games/b.md)は参考情報です。
現在の登録・対応状況は上の一覧を確認してください。
